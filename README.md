# Кузов Межгород

Сайт грузоперевозок фурами по коридору Москва — Казань — Екатеринбург: демо приложения заказа, подбор кузова под груз с ориентировочной ценой и заявка на перевозку.

Сайт статический: всё в `index.html`, сервер не нужен. Публикуется через GitHub Pages: https://kirillsorazvitie-rgb.github.io
